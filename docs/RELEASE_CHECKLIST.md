# Чек-лист ручного тестирования перед релизом HomeEase 2.0

Выполните после деплоя на staging/production. Отметьте ✅ при успехе.

## Авторизация

- [ ] Регистрация нового пользователя (email + пароль ≥ 8 символов)
- [ ] Ссылки на Политику конфиденциальности и Условия на экране регистрации
- [ ] Вход существующего пользователя
- [ ] Выход / повторный вход

## Роли и навигация

- [ ] Экран выбора роли: «Опытная мама» и «Молодая мама»
- [ ] Кнопка «Выход» → экран регистрации
- [ ] Дашборд домохозяйки: иконки 3+2, фон на весь экран
- [ ] Дашборд молодой мамы: иконки 3+3, фон на весь экран
- [ ] Розовый таб-бар, переключение вкладок

## Домохозяйка

- [ ] Создать список покупок, добавить товар, отметить купленным
- [ ] Создать объявление бартера
- [ ] Создать задачу, записать время в отчёт

## Молодая мама

- [ ] Записать кормление
- [ ] Записать сон
- [ ] Добавить пункт в чек-лист

## Подписка

- [ ] Профиль → «Тарифы и подписка»
- [ ] Отображаются цены месяца и года в местной валюте
- [ ] Отображается статус (триал / активна / истекла)
- [ ] Выбор плана (месяц/год) с выделением
- [ ] Кнопка «Оформить» → checkout (mock или YooKassa test)
- [ ] После оплаты (или mock URL) статус обновляется
- [ ] Deep link `homeease://payment/success` обновляет подписку
- [ ] Отмена подписки (если активна платная)

## Локализация

- [ ] Переключение языка (минимум ru + kk)
- [ ] Экран подписки на выбранном языке

## Production-инфраструктура

- [ ] `GET /health` → 200
- [ ] `GET /health/ready` → `{"status":"ready","database":"ok"}`
- [ ] CORS: фронтенд на production-домене обращается к API
- [ ] Webhook YooKassa (тестовый платёж) активирует подписку
- [ ] Sentry получает тестовую ошибку (если настроен DSN)
