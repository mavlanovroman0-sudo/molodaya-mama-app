Сервис «молодая мама»: https://my-molodaya-mama.ru

Сервис «молодая мама» («мы») обрабатывает персональные данные для предоставления сервиса.

1. Какие данные собираем: email, имя профиля, выбранная роль, геолокация (страна, город, район), данные о подписке, история использования функций приложения.

2. Цели обработки: авторизация, персонализация, расчёт тарифов по региону, работа подписки, реферальная программа, техническая поддержка.

3. Передача третьим лицам: платёжные провайдеры (YooKassa, RuStore, Т-Банк) получают только данные, необходимые для оплаты. Мы не продаём персональные данные.

4. Хранение: данные хранятся на защищённых серверах. Вы можете запросить удаление аккаунта через поддержку.

5. Cookies и аналитика: веб-версия может использовать технические cookie; при наличии системы сбора ошибок они отправляются без персональных данных.

6. Контакты: support@my-molodaya-mama.ru
